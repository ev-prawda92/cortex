Get Started See Architecture
# Deploy in 30 seconds
$ git clone https://github.com/cortex-ai/cortex.git
$ cd cortex && docker compose up -d
# That's it. Open http://localhost:3000
# Or run an agent via API
$ curl -X POST localhost:3000/api/agents/my-bot/run \
    -H "Authorization: Bearer ctx_..." \
    -d '{"message": "Summarize Q3 results"}'

CAPABILITIES
Everything you need to run agents safely at scale
Cortex doesn't own your data or lock you into a provider. It controls access, enforces policy, and gives you a full audit trail.
🔗

Provider-Agnostic Runtime

Swap between Anthropic, OpenAI, and Google models with a single setting change. No vendor lock-in, ever.

📜

Tamper-Evident Attestation

Every agent action creates a hash-chained provenance record. Verify the entire chain with one click. Built for compliance.

🛡️

RBAC & Human Approvals

Role-based access with per-agent scope overrides. Gate high-risk actions behind human approval workflows.

📊

Usage Analytics

Real-time dashboards: token usage, run volume, latency percentiles, cost tracking, success rates — all in one view.

🔔

Webhooks & Notifications

HMAC-signed webhook delivery for run events. In-app notifications with real-time badge updates. Never miss an escalation.

🧠

Embedded AI Assistant

Context-aware AI chat built into the monitoring page. Ask questions about your agents using live production data.

📦

Agent Templates

Save and share agent configurations as reusable templates. One-click clone from a curated template library.

🔑

API Keys & OAuth

Scoped API keys for programmatic access. Google and GitHub SSO for team authentication.

🐳

One-Command Deploy

Docker Compose for local dev, ready for Kubernetes. PostgreSQL for reliability, environment variables for config.
