## The 5-Minute Overview

**What Cortex does:**
- Register agents (from Claude, OpenAI, or custom code)
- Monitor health, cost, errors, latency
- Roll back to any previous version
- Collaborate across teams
- Audit everything (who changed what, when)

**What Cortex doesn't do:**
- Build agents (that's Claude, OpenAI, your codebase)
- Consult on your business model (that's on you)

**Who uses it:**
- Consultancies operating agent products for multiple clients
- Enterprises managing internal agent portfolios
- Anyone deploying multiple agents and needing visibility
